# Desktop implementation and outstanding release evidence

Updated29 October2026. The requested scope includes every roadmap workstream except Android/iOS. A working subset is identified below; this document does not reduce that scope or certify an unfinished capability. Windows source, native-harness evidence, packaged acceptance and live services are separate checkpoints.

| Surface | Current executable behavior | Remaining work or evidence |
|---|---|---|
| Transfers and media | Adaptive HTTP range splitting, host scheduling and rate control; reviewed HLS/DASH acquisition; verified stream-copy assembly through an explicitly pinned FFmpeg helper. See TRANSFER-EVIDENCE.md and MEDIA.md. | Broader origin/expiry behavior, installed-browser trust paths and failure corpus; full journal/finalization fault matrix and platform measurements. DRM and credential extraction are excluded. |
| Queues | Persistent download queues, membership, held jobs, retries, limits and time-zone schedules. Sync queues recheck validators and retain new versions beside originals; network-cost policy holds covered work without resuming manually paused jobs. | Packaged queue acceptance and broader platform measurements. Sync queues do not mirror arbitrary directory trees. Unknown network cost remains explicit. See QUEUES-NETWORK.md. |
| Downloads | Native daemon supervision, paged jobs, inspectors and batch controls; bounded durable journal replay and atomic display-history cache. Failed or overlapping reads retain successful rows. | Continuous push delivery, atomic snapshots spanning pages and large-list installed accessibility/virtualization evidence. See DESKTOP-EVENT-RECOVERY.md. |
| Workflow runs | Closed native plan/validate/dry-run/run/list/get/control/manifest routes; saved exact plans, fresh review after reopening, paged reports, visible read failures and stable mutation retry receipts. Public-page and bounded sitemap/gzip acquisition execute through CLI/MCP and desktop. | Authenticated document/render access, infinite scroll, item sinks, conversion and revised-plan continuation. New effects require new review. See ADR0017. |
| File workspace | Scoped retained-handle index, paged live folders, optional real Everything broker, two panes, selected-file comparison, copy/move/delete/undo, ZIP jobs, previews and duplicate inspection. | Engine and delete/trash capability conversion; independent USN/MFT/content indexing; allocation/hard-link accounting; recursive comparison/synchronization and crash-resumable copies. Existing receipt persistence is not a same-user sandbox. See ADR0016 and FILE-WORKSPACE.md. |
| Library and organization | Paged artifact records, metadata/lineage, record-only local ingest, reviewed retention/materialization/tombstones; deterministic organization preview/request/undo with durable progress. ADR0018 narrowly adds file writes to the default app credential. It never adds approval decisions or borrows another credential. | Model-generated rule proposals, workflow conversion and artifact import/export/events/collection administration/migrations. Registration does not imply a stored content copy. |
| Uploads and sources | Reviewed cloud delivery and provider-owned OAuth/storage adapters; owner-scoped connected S3/Hub/torrent sources with plan/review, bounds, verified publication, operation controls and restart handling. | Live provider registrations/accounts and broader provider matrices. Torrent support uses explicit peer addresses; it does not advertise tracker/DHT/magnet discovery or seeding. See SOURCE-ADAPTERS-PLAN.md and CLOUD-OAUTH.md. |
| Inbox and agent | Durable owner-scoped intake packages, bounded immutable review and dispatch receipts;15-tool MCP catalogue and explicit read/mutation policy. Five installed-agent presets use official local CLI protocols, including Grok ACP; BYOK remains available. | Package rules and durable handoff from every intake; human GUI package inspection; actual subscription inference and external-host acceptance. CLI discovery is not proof of a valid subscription. |
| Optional team service | Native Team page, pinned signed restrictions, metadata CAS/tombstones, OIDC/PKCE device enrollment, session rotation/revocation, signed client-reported provenance and audit chain. | Owner-selected Dex client/administrator/TLS deployment and login-page handoff are verified. Human owner sign-in and live two-tenant acceptance remain. Configuration absent means local mode; an invalid configured restriction holds covered new effects. It cannot grant local file/transfer approval. See TEAM-SERVICE.md. |
| Distribution | Windows alpha packaging includes the app, runtime and Everything helper; browser extension archives are rebuilt at the alpha version. Core and extension PRs are merged. | Zeus packaged acceptance passes41 checks; release publication and remaining VPS runtime rollout; signing/store identities and hosted CI billing require their real operational inputs. Prior Linux packages do not count as alpha desktop evidence. |

The detailed roadmap remains open wherever the final column names implementation work. The Go Bubble Tea/Lip Gloss client and device-wide transfer takeover remain the separately requested feasibility study; no proxy, root certificate, driver or network interception has been installed. See DEVICE-WIDE-TUI-FEASIBILITY.md.
