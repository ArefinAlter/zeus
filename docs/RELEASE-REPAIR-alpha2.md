## Windows controlling-console repair — 31 October 2026

Final Edge handoff acceptance exposed a Windows release blocker: `zeus approvals approve` refused a real console with `api.human_required`. The CLI and daemon's offline trust-review path opened CONOUT$ write-only, while Rust's `IsTerminal` uses [GetConsoleMode, which requires GENERIC_READ](https://learn.microsoft.com/en-us/windows/console/getconsolemode). Both paths now request read access only on Windows; terminal detection is retained.

A native child-console regression fails before repair. Shared test support now checks both a newly allocated console with redirected standard IO and a detached child: the former must be accepted and the latter refused. Both regressions pass, and the complete Windows root suite passes 709 tests, strict Clippy, formatting and Rust 1.90. The runtime is rebuilt. Real Edge terminal completion and final packages remain pending at this checkpoint. The older af08878 package candidates were not published and must be superseded; sidecars must be rebuilt for the new source revision.

## Scope and limits

- HTTP(S), local file/index/archive/organizer/storage features and reviewed agent actions are exercised with controlled fixtures. External cloud account transfers and live provider inference are separate gates, not implied by discovery tests.
- The TUI shares jobs/files/cloud status and controls with the desktop. Full indexed search, advanced file operations and natural-language agent tasks remain desktop functions.
- FTP and BITS are not implemented transports. Existing torrent/source paths require their own acceptance. Browser handoff cannot promise interception of every application or protocol.
- External MCP remains bounded and read-only until a separately trusted human review channel is implemented. Desktop review does not approve daemon/browser terminal requests.
- Development extensions need explicit manual installation consent and host pinning. Popup and terminal once-only decisions both pass; no store publication or signing is claimed.
- Zeus's public demo was retired with HTTPS 410. Dynodoc signed-in services were preserved. Earlier SSH/HSTS changes remain staged.
