# Download workspace prototype

Open `index.html` in a browser. No server, dependency installation or network connection is needed. The prototype uses local HTML/CSS/JavaScript and in-memory sample data. Reload resets every action.

Try filtering the queue, selecting files and pausing them; importing a few example URLs; changing a run budget; reviewing the sample request with code `17M-4F1`; and engaging/releasing global stop. A release leaves jobs paused. No action downloads files, grants permissions or contacts the daemon.

The sample approval binding is illustrative, not cryptographic evidence. Production approval UI must recompute current facts and use Zeus's authenticated native or terminal trust channel. Schedule and workflow controls are proposals.

See [the design decisions and source references](../download-workspace.md).
